# Progressive cross-book retrieval

## Retrieval ladder

1. **Concept index:** Read `library/concepts.md`. Match the current problem by
   concept, mechanism, tension, decision, contradiction, application, personal
   trigger, or open question. Do not open every book.
2. **Cards:** Select at most three candidates and read only their `04-card.md`
   files. Prefer structural or contradictory matches over shared tags.
3. **Personal dialogue:** Open relevant headings in `03-core-dialogue.md` when
   the reader's prior judgment, disagreement, action, or unresolved question
   matters.
4. **Deep analysis:** Open targeted portions of `02-deep-reading.docx` only when
   the answer needs the author's reasoning, evidence, assumptions, or boundary.
5. **Source check:** Return to `01-source.*` only when an interpretation is
   disputed or exact evidence is needed.

Stop at the shallowest layer that answers responsibly.

## Connection types

- **DIRECT:** both books explicitly treat the same concept.
- **STRUCTURAL:** different language describes the same underlying mechanism.
- **ANALOGICAL:** domains resemble each other, but the mechanisms are not yet
  established as equivalent.
- **CONTRADICTORY:** assumptions, explanations, or recommendations conflict.
- **COMPLEMENTARY:** one book supplies a missing level or mechanism.
- **BOUNDARY:** one book shows where another stops working.

Do not count theme similarity alone. State the exact distinction, prediction,
decision, or action that changes.

## Response levels

- **Level 0 Current question:** answer directly without mentioning old books.
- **Level 1 Subtle connection:** mention one relevant earlier idea in one or two
  sentences.
- **Level 2 Structural connection:** explain the shared mechanism and the
  important difference.
- **Level 3 Synthesis:** combine multiple books only when their convergence or
  conflict produces a genuinely stronger model.

If the index has no strong match, say so instead of producing a decorative
analogy. Do not use cross-book retrieval to display how much the system knows.
